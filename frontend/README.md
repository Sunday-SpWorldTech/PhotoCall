# PhotoCall Frontend

This is the separate Vite frontend. It does not start the backend.

## Run locally

```powershell
cd "C:\Users\USER\PhotoCall\frontend"
npm install
npm run dev
```

The frontend normally runs at `https://photocall-frontend.vercel.app/`.

The backend runs separately at `https://photocall-backend.vercel.app/`.

Frontend environment variables belong in `.env` and are intentionally not committed by Git. Keep `.env.sample` as the template.
